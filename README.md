🚀 Descripción del Proyecto
Movilidad para Todos CDMX es una aplicación móvil inclusiva que optimiza rutas urbanas en tiempo real para personas con discapacidad motriz y ciclistas. Utiliza tecnologías como realidad aumentada (AR), crowdsourcing y sensores IoT para mejorar la accesibilidad, seguridad y autonomía en la Ciudad de México.

Este proyecto forma parte del Hackaton PILARES 5.0 en la categoría Ciudad Innovadora, y busca contribuir a una CDMX más sustentable, inclusiva y conectada.
